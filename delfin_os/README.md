# دلفن OS — حزمة مختبَرة (93 اختباراً)

بلا اعتماد على أي حزمة خارجية (مكتبة بايثون القياسية فقط)، فتعمل في Termux كما هي.

## التشغيل في Termux
```
tar -xzf ~/storage/downloads/delfin_os.tar.gz -C ~/Marsad/ && cd ~/Marsad/delfin_os
python3 -m unittest discover -s tests -t .          # يجب أن ترى: OK
python3 -m delfin init                              # يطبع مفتاح المدير مرة واحدة: احفظه
export DELFIN_LLM_URL="https://<رابط-النفق>/v1" DELFIN_LLM_KEY_FILE=~/.marsad_secrets/llm_key
python3 -m delfin serve                             # http://127.0.0.1:8787/dashboard
python3 -m delfin verify                            # فحص سلامة الكود وسجل التدقيق والقيود
```
بعد أي تعديل مقصود على `delfin/security|sandbox|safety|core` شغّل `python3 -m delfin manifest` ليُعاد توقيع البصمات،
وإلا سيدخل النظام وضع الصيانة (قراءة فقط) عند التشغيل.

## ما لا يزال غير حقيقي أو غير مُجرَّب (بصراحة)
- **العزل المحلي ليس عزلاً حقيقياً**: `LocalSandbox` مقفل افتراضياً. تنفيذ الكود يحتاج `RemoteSandbox` (غير مُتحقَّق من مسار/رد main.ts) أو حاوية.
- **وسيط GitHub** مُختبر بنقل وهمي فقط؛ لم يُجرَّب على GitHub الحقيقي. يحتاج GitHub App وحماية فرع `main` من إعدادات المستودع.
- **المتصفح** مُختبر بجالب وهمي؛ الاتصال المثبَّت على العنوان لم يُجرَّب على الإنترنت.
- **Telegram** و**النوت بوك** لم يُشغَّلا فعلياً (لا شبكة/Kaggle هنا).
- **المدقّق النموذجي** من نفس عائلة النموذج: أخطاؤهما متشابهة. الأفضل نموذج مختلف.
- **سجل التدقيق** يكشف التلاعب ولا يمنعه؛ المنع يحتاج نسخة خارجية.
- **حَكَم v2** مقياس تقريبي لا إثبات؛ الإثبات يحتاج تشغيل اختبارات المشروع على الرقعة.
- **غير موجود بعد**: Webhooks، استرجاع معرفة الشركة (RAG)، TLS، مجموعة تقييم محجوبة فعلية في مستودع منفصل.

## نشر ملفات Kaggle المصلحة (مجلد deploy)
1. انسخ `deploy/challenge/*` إلى `Marsad/challenge/` وارفعها بـ git، وراجع التغيير بنفسك.
2. ضع في Kaggle Secrets: `HF_TOKEN` (دقيق الصلاحيات) و`MARSAD_REF` (بصمة الـ commit التي راجعتها) و`GGUF_SHA256`.
3. `bash deploy/push_to_kaggle.sh` (يفحص الأسرار قبل الرفع). وتحكّم بـ `bash deploy/control_send.sh run|pause|stop|status`.
4. تأكد أن `core/agent_loop.get_agent()` يقرأ `MARSAD_LLM_URL` و`MARSAD_LLM_KEY` و`MARSAD_LLM_MODEL`.
