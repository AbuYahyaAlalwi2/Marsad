# تشغيل MARSAD على اللابتوب

## 1. متطلبات أولية
- Python 3.11+
- pip محدّث

## 2. تثبيت المكتبات
pip install -r requirements-laptop.txt

## 3. تشغيل النظام
python dashboard_api.py

سيفتح المتصفح تلقائياً على http://localhost:5000

## 4. تشغيل حلقة كاملة (اختياري)
python main.py

## 5. المميزات على اللابتوب
- mergekit — دمج نماذج حقيقية (يحتاج torch)
- Daytona sandbox — بيئة معزولة للكود
- Pydantic AI critic — مراجعة متقدمة
